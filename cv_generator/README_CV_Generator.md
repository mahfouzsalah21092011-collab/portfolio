# Mahfouz Salah CV generator

## Files
- `generate_cv.py` — Python source that generates the editable Word CV and PDF.
- `Mahfouz_Salah_CV_RDD_MEP.docx` — editable Word output.
- `Mahfouz_Salah_CV_RDD_MEP.pdf` — PDF output.
- `requirements.txt` — Python dependencies.

## Run
Use Python 3.10+ and install dependencies:

```bash
python -m pip install -r requirements.txt
python generate_cv.py
```

The script writes the DOCX and PDF into the same directory.

## Important
This CV is a draft. Verify the candidate's contact details, dates, job titles,
project names, project counts, and responsibilities before sending it to employers.
The script is a reproducible generator based on the CV draft content, not a record
of an independently verified employment history.
